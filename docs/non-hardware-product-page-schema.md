# 非硬體產品頁內容 Schema

更新日期：2026-07-06

本文件定義不適合套用「硬體產品規格詳情」模組的產品頁處理規則。這些頁面仍可被優化，但不得為了通過產品規格表 QA 而編造型號、性能、尺寸、下載檔或表格欄位。

## 適用範圍

| 269 | ACS 教育訓練影片 | 教育訓練 / 影片資源 | `training-resource-page` |

## 共通原則

- 不建立硬體型號規格表，除非後續取得明確官方硬體規格來源。
- 不新增未驗證的型號、性能、尺寸、電氣規格、相容性或下載檔。
- 若頁面要保留在前台，需維持一頁一 H1、清楚 H2/H3、可見 CTA、正確 canonical 與 breadcrumb。
- 若有下載或影片，連結需有可辨識文字；不可使用空白按鈕或 `href="#"`。
- 若資訊不足，顯示「請洽星泰」或保留既有內容，不自行推測。

## `software-page`

適用於 ACS 軟體、工具、設定平台或韌體相關頁。

建議模組順序：

1. `軟體簡介`
2. `主要功能`
3. `適用產品 / 相容性`
4. `下載與文件`
5. `導入與技術支援`

必要資料欄位：

- 軟體名稱
- 用途 / 功能摘要
- 適用硬體或控制器系列
- 下載狀態：官方下載、星泰提供、請洽星泰
- 文件類型：Manual、Software、Release note、Application note

## `informational-page`

適用於品牌特點、技術特性、系統能力說明頁。

建議模組順序：

1. `內容簡介`
2. `核心功能`
3. `適用情境`
4. `相關產品`
5. `技術諮詢`

必要資料欄位：

- 主題名稱
- 功能或技術重點
- 適用產品線
- 是否有官方來源或原廠頁面
- 詢問 / 技術諮詢入口

## `training-resource-page`

適用於教育訓練影片、課程、操作教學、教學資源頁。

建議模組順序：

1. `教育訓練簡介`
2. `課程 / 影片列表`
3. `適合對象`
4. `相關產品`
5. `預約諮詢`

必要資料欄位：

- 課程或影片名稱
- 主題摘要
- 適合對象
- 影片或資源連結
- 是否需要登入、預約或人工提供

## `exclude-test-page`

適用於測試頁、後台殘留頁、未確認公開用途頁。

處理規則：

- 不建立產品規格詳情。
- 不主動優化成公開頁。
- 若業主確認要公開，必須先重新定義頁面目的與 schema，再進行內容與 SEO 優化。

## 驗收規則

非硬體頁若進入後續優化，至少需通過：

- 無 `href="#"`、`.txt`、`file:///`、本機磁碟路徑。
- 無 `pending`、`placeholder`、`data-local-file` 或開發人員註解。
- H1 / H2 / H3 結構清楚。
- CTA 為真實可點擊連結或明確「請洽星泰」狀態。
- 不出現硬體規格表專用欄位，除非有官方來源支持。
