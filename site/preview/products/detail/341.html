捲材張力控制系統

介紹

FMS-segFORCE

分段式張力監測系統

業界唯一能提供「全幅寬張力分佈圖 (Tension Profile)」的測量系統。單根張力輪可配置多達 50 個獨立傳感器，精確捕捉每一條分切材料的張力差異，讓隱藏的製程瑕疵無所遁形 。

系統亮點
  • • 無限靈活： 自由移動與增減測量段。
  • • 無線材干擾： 軸內走線，外觀簡潔俐落。
  • • 工業互聯： 支援 PROFINET / EtherCAT。

segForce Datasheet
One System, Infinite Possibilities

單一系統，無限配置
FMS-segFORCE 分段式張力輪

FMS-segFORCE 不是死板的標準品，而是一套靈活的積木。無論材料寬度是 200mm 還是 2000mm，分切成 5 條還是 50 條，我們都能透過模組化組件為您量身打造。

自由定義您的測量輪

快速適應不同工單

這種設計讓同一根輥輪可以適應多種不同的分條工單。操作員只需透過氣壓開關，就能在幾分鐘內重新排列感測器位置，無需專業工具。

系統由一根剛性軸心與多個獨立的測量段組成。您可以自由選擇測量段的寬度與數量，並透過氣壓解鎖，將它們滑動到任意位置。

  • ✓ 最大輪寬可達 2000 mm
  • ✓ 最多支援 50 個獨立測量通道

無線材干擾的俐落外觀

簡化安裝與配線

外部僅需連接一條 24V 電源與一條網路線，大幅降低安裝難度與維護成本。且採用標準軸承座孔位，可輕鬆替換現有惰輪。

傳統多點測量往往伴隨著混亂的電纜線。FMS-segFORCE 採用獨家軸內訊號傳輸技術，供電與數據都通過軸心內部傳輸。

  • ✓ 僅需一條網路線即可傳輸所有數據
  • ✓ 標準軸承座安裝，無縫升級

應用領域

分條複捲機 (Slitter)
監控每一條分切後的窄幅材料張力。快速發現並修正滑差軸 (Differential Shaft) 的故障。
精密塗佈 (Coating)
利用張力分佈圖監控基材平整度。即時發現塗佈不均或材料變形，確保高品質產出。
母捲品質檢測
在材料進入產線前，快速評估母捲 (Parent Roll) 品質，剔除有荷葉邊或鬆緊邊的不良品。
FMS Analysis Tool
專用分析軟體，能以 2D/3D 圖表顯示張力分佈。支援 HDF5 格式導出，方便大數據分析。
