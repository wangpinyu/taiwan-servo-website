步進馬達

JVL整合型伺服馬達及步進馬達的特色

介紹

馬達與驅動器一體化設計：
內建驅動、信號與動力線，省佈線、省空間、省成本
簡化安裝與售後：
降低接線錯誤與干擾風險，提升現場服務效率
通訊多樣化：
支援 Pulse/Dir、A/B 相、±10V 類比、數位 IO
通訊協定全面支援：
  • 串列埠：RS-232 / RS-422 / RS-485
  • 現場總線：CANopen、Profibus DP、DeviceNet
  • 工業乙太網：EtherCAT、EtherNet/IP、
  • Profinet IO、PowerLink、Modbus TCP/IP、Sercos
  • 無線：WLAN、Bluetooth、ZigBee
韌體升級可轉換乙太網通訊協定，提升系統整合彈性

JVL整合型伺服 步進馬達

MAC 系列（整合型伺服馬達）

功率範圍：50W～4.5kW（0.11～14.3Nm）
  • 電壓選擇：12～48VDC、90～240VAC、3x400VAC
  • 編碼器解析度：最高 8192 cpr，支援多圈絕對式 SSI
  • 防護等級：IP42、IP55、IP66、IP67（依型號而異）
  • 剎車選項：內建或外加煞車
  • 不鏽鋼與防水型可選：IP67 密封，適合食品/濕環境
型號 功率 (W) 連續/峰值扭矩 (Nm) 防護等級 特殊型式
MAC050-141 46–134 0.11–0.48 / 0.32–1.59 IP42/IP67 精巧型、防水型
MAC400-800 400–734 1.28–2.38 / 3.8–6.8 IP55/IP66 標準型、防潑水
MAC1200-4500 1140–4500 3.8–14.3 / 11.4–52 IP55/IP67 高功率型、重工業應用

MIS 系列（整合型步進馬達）

扭矩範圍：0.36Nm～25.0Nm（NEMA17~NEMA43）
  • 電壓支援：12–72VDC
  • 控制精度：標配 409600 cpr 微步分割，部分型號可選擇 200～1600 cpr
  • 閉迴路控制：可搭配增量/絕對式編碼器
  • 防護等級：IP42 或 IP65（依型號）
機型 (NEMA) 型號範圍 扭矩範圍 (Nm) 電流範圍 (A) 特殊功能
NEMA17 MIS171~176 0.36～0.80 約2.7～3.3 高密度迷你型
NEMA23 MIS231~234 0.97～3.08 約3.5～6.7 標準型
NEMA34 MIS340~343 3.0～12.0 約5.0～6.6 中大型應用
NEMA43 MIS430~432 10.0～25.0 最高6.6 高扭矩重載型

Linear Stepper Motors（直線步進馬達）

  • 型號 MIL17 / MIL23 / MIL34
  • 可選擇：內建電動缸（piston）/ 開放式螺桿 / 滾珠螺桿
  • 整合驅動控制器、尺寸緊湊，適用於線性精密移動應用

SMC 步進馬達控制器系列

控制器型號 最大電流 內建功能 保護等級 通訊支援
SMC75 3A PLC/RS422 IP42 / PCB SSI / CANopen
SMC66 6A PLC/RS422 IP42/IP65 EtherCAT / Profinet 等全通訊支援
SMC85 9A PLC/RS422 IP42/IP65 同上，適用大電流步進馬達
其他功能包含：
  • 可程式化控制（8IOA）
  • 支援閉迴路控制、齒輪比設定
  • 精度可達 0.01RPM 速度控制

配件與擴充模組

  • 支援 M12接頭、防水電纜、直接出線與D-SUB接口
  • MAC 系列擴充模組包含：通訊模組（EtherCAT、Profinet等）、編碼器模組、剎車模組、多I/O擴充模組（MAC00系列）
  • 編碼器選配：增量 / 絕對式（多圈 / 單圈），介面支援 ABZ、SSI、BISS-C 等
