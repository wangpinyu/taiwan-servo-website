KOLLMORGEN

KOLLMORGEN AKD PDMM伺服控制器

特點
高整合性：單一設備具備驅動與主控雙重功能
可用於分散式或集中式控制架構
支援多種電源與電流需求
對應 多軸同步控制應用，例如包裝、裝配、加工機械等

介紹

AKD PDMM® 是 Kollmorgen 所推出的一體式多軸運動控制解決方案，將 伺服驅動器 與 多軸主控制器 結合於單一模組中：

  • 集成 1個內建伺服軸 + 最多支援7個外接AKD驅動軸
  • 提供完整的運動控制、自動化整合與 I/O 控制功能
  • 相容於 Kollmorgen Automation Suite™：具備可擴展開發環境、HMI整合、多軸同步控制

產品定位
AKD servo drive + embedded motion controller integrated in one package
最大軸數
Kollmorgen product page / support page states control up to 64 axes; actual count depends on motion and automation complexity.
開發環境
Kollmorgen Automation Suite; IEC 61131-3 soft PLC; PLCopen or Pipe Network motion programming.
處理器版本
MC / MCEC = 800 MHz CPU; M1 / M1EC = 1.2 GHz CPU.
I/O
Product page lists 13 digital inputs, 4 digital outputs, 1 analog input, 1 analog output.
回授支援
SFD, EnDat 2.2 / 01, BiSS, analog sine/cos encoder, incremental encoder, HIPERFACE, resolver.
