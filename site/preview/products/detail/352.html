ACS Application Development

軟體定義運動控制
全方位開發與模擬環境

ACS 軟體生態系統不僅僅是驅動程式，它是工程師的強大軍火庫。從 SPiiPlus MMI 的直覺調校、Simulator 的離線模擬，到支援 C#/Linux/MATLAB 的豐富函式庫，我們協助您以最短時間實現最複雜的控制演算法。

MMI Studio：您的控制中心

SPiiPlus MMI 是所有 ACS 控制器的核心介面，整合了 EtherCAT 網路配置、伺服參數調校 (Tuning)、ACSPL+ 程式撰寫與即時示波器 (Scope) 診斷功能。

直覺式開發與診斷

不再需要切換多個視窗。MMI Studio 內建了強大的 8 通道示波器，能以高達 20kHz 的頻率即時擷取位置誤差、速度與電流波形。搭配自動調校精靈 (Auto-Tuner)，即使是複雜的雙驅龍門系統，也能在幾分鐘內完成 PID 優化。

Simulator：硬體未到，軟體先行

SPiiPlus Simulator 是完整的虛擬控制器。它能在您的 PC 上模擬真實控制器的所有邏輯與運動行為，讓軟體開發不再被硬體交期卡住。

縮短上市時間的利器

透過 Simulator，您可以在辦公室內開發並驗證複雜的 ACSPL+ 程式與 C#/C++ 上位機軟體。它不僅模擬邏輯，還能模擬多軸插補運動與 I/O 互動，確保您的程式碼在連接真實機器時能「一次成功」。

無縫整合上位系統

ACS 提供封裝完整且高效率的 API 函式庫，支援 C#, C++, VB.NET, LabVIEW 與 Python，讓上位機通訊變得簡單可靠。

Host Application Libraries

ACS 的通訊函式庫支援多執行緒 (Multi-threading) 與回調函數 (Callback)，能即時處理大量數據傳輸與事件觸發。這讓您的 HMI 介面能即時顯示馬達位置，並高速下達運動指令。

核心開發工具模組

Advanced Analysis Libraries

整合 MATLAB 與頻率響應分析 (FRF) 工具，專為運動控制性能優化與大數據分析設計。

  • FRF Analyzer: 產生 Bode/Nyquist 圖表
  • Matlab Lib: 與 Simulink 無縫整合
  • 精確識別機械共振與系統頻寬

行業應用實例

半導體與面板設備
利用 ACSPL+ 實現複雜的雙驅龍門 (Gantry) 同步與高速循圓補間，確保奈米級定位精度。
雷射微加工
透過 G-Code 與位置比較觸發 (Position Pegging) 功能，實現雷射脈衝與運動路徑的精確同步。
電子組裝 (SMT/Die Bonder)
利用 Simulator 優化取放 (Pick-and-Place) 路徑，並透過 Host Libraries 與視覺系統高速通訊。

ACS Motion Control Software Suite

產品規格詳情

本區整理 ACS 官方 Application Development 軟體生態系統的主要模組：SPiiPlus ADK Suite、MMI Application Studio、Controller Simulator、Host Application Libraries、Advanced Analysis Libraries、G-Code Programming、Real-Time C Function 與 ACSPL+ Programming。內容僅保留官方頁面可查核的軟體能力與支援項目。

SPiiPlus ADK Suite

ACS 產品的應用程式開發套件，整合產品設定、運動效能調校、控制器端程式撰寫、主機端應用程式開發與支援資源。

  • 包含 MMI Application Studio
  • 包含 Controller Simulator
  • 包含 Host Application Libraries

MMI Application Studio

用於開發與維護進階多軸運動控制應用的軟體套件，並納入 SPiiPlus ADK Suite。

  • System Setup：EtherCAT 網路設定
  • Adjuster Wizard：軸向設定與調校
  • Program Manager：多執行緒程式開發
  • Multi-channel Scope：含 XY mode 的資料分析

Controller Simulator

可在無硬體狀態下開發與測試控制器端、主機端應用，並模擬機台輸入與故障條件。

  • 支援 ACSPL+ 程式開發與測試
  • 支援 host application 測試
  • 可用於錯誤處理流程的模擬驗證

Host Application Libraries

ACS 官方列出多種主機端函式庫，適用於 OEM 人機介面與上位控制系統開發。

  • C、.NET、Low-Level、Linux、Python、MacOS Library
  • Matlab 與 FRF Library 屬 Advanced Analysis Libraries
  • 最多 10 個同時通訊通道
Advanced Analysis Libraries 包含 FRF Analyzer Library 與 MATLAB Library；支援 C、.NET、MATLAB frameworks，並可與 MMI Application Studio 的 FRF Analyzer 共用功能。
G-Code Programming 適用於高精度雷射加工與 CNC 類應用；支援標準 G/M code、使用者自定義 G/M code、Simulator、Segmented Motion 或 SmoothPath 輪廓運動模式，官方列出最高 5,000 blocks/second processing rate。
Real-Time C Function 可用 C 語言在 Visual Studio 中開發專屬函數，於 SPiiPlus 控制器即時執行；官方列出即時資料處理、吞吐優化、Simulator 搭配、IP protection 與 error handling。
ACSPL+ Programming ACS 控制器使用的 real-time multi-threaded programming language；官方列出最高 10kHz program execution rate、最多 64 個同時執行 buffers，以及點對點、tracking、contour、splines 等多軸運動模式。
