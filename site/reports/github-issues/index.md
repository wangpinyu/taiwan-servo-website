## 執行規則

- 每個 issue 綁定一個產品分類或品牌。
- 對應 PR 完成後，在 issue 中補上 QA 報告與 AI review 狀態。
- `source-needed` 表示官方來源或下載映射不足，不應自行補寫規格。
- `blocked-server-large-file` 是伺服器或大檔限制，不阻塞本機 preview 優化。
