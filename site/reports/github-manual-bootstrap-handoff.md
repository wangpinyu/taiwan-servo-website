1. 先確認已登入 GitHub 且 repo 可進入。

4. 先建立 phase-1-smac-spec-standard PR；其餘 PR 可等 phase 1 接受後再開，或依 base branch 建立 stacked PR。
5. 建立後執行 npm run workflow:github-remote-verify 與 npm run validate:external-handoff。
