固態繼電器

面板安裝型固態繼電器

介紹

PANEL MOUNT SSR

Industrial Solid State Relays

工業級面板安裝型固態繼電器。專為大電流負載設計，提供單相、雙路及三相控制選擇，是加熱與馬達控制的最佳方案。

● 10A - 100A 大電流
● 內建過壓保護 (TVS/MOV)
● LED 狀態指示燈

Heavy Duty Control

穩定耐用，駕馭大功率負載

i-autoc 面板安裝系列 (Panel Mount) 是工業自動化中應用最廣泛的標準品。具備優異的散熱底板設計與高強度外殼，能輕鬆應對加熱爐管、注塑機與大馬達等嚴苛負載。

 

優異的熱管理與防護

全系列採用 **DBC (Direct Bonded Copper)** 陶瓷基板技術，將功率晶片的熱量快速傳導至金屬底板。搭配選配的散熱片 (Heatsink)，即使在滿載運作下也能保持低溫高效率。

  • ✓ 內建 RC 緩衝電路，抵抗突波干擾
  • ✓ 具備 LED 輸入狀態指示燈，除錯方便

產品規格總覽

 

全方位滿足直流、單相、三相與雙路控制需求

1. 直流輸出型DC OUTPUT
KSJ / KSJM

MOSFET 高速控制

專為 DC 負載設計，提供低阻抗、高速開關能力。適用於電池、太陽能與直流馬達控制。

負載電壓 0 - 100 / 600 / 1200 VDC
負載電流 10A - 100A
技術特點 MOSFET / IGBT Output
2. 單相交流型SINGLE PHASE AC
KSN / KSIE

標準工業控制首選

採用 SCR 反並聯輸出，耐衝擊電流強。廣泛應用於塑膠機械、溫控系統與照明控制。

負載電壓 24 - 280 / 480 / 660 VAC
負載電流 10A - 125A
技術特點 Zero-crossing / Random
3. 三相交流型THREE PHASE AC
KSQE

三相馬達專用

雙色 LED 指示燈，一體化三相控制。內建 RC/MOV 保護電路，確保三相馬達啟動平穩。

負載電壓 48 - 530 VAC
負載電流 25A / 40A / 60A / 80A
技術特點 Internal MOV Protection
4. 雙路交流型DUAL CHANNEL AC
KSJB / KSJD

空間節省雙倍輸出

單一模組內建兩組獨立 SSR，節省 50% 安裝空間。適合密集型加熱控制應用。

負載電壓 24 - 280 / 530 / 660 VAC
負載電流 25A / 40A / 50A (Per Ch)
技術特點 Independent Control

行業應用實例 (Applications)

 
注塑機加熱控制

SSR 能進行高頻率的 PID 溫度控制，確保料管溫度恆定，提升塑膠成型品質。

適用: KSN / KSQE
 
電池儲能系統

直流 SSR 用於電池充放電管理與保護電路。低阻抗特性減少能量損耗，提升系統效率。

適用: KSJ / KSJM
 
多區溫度控制

雙路 SSR 允許在極小的電控箱內控制多組封口加熱器，是包裝機械輕量化的關鍵元件。

適用: KSJB / KSJD
