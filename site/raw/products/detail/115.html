核心優勢 Key Benefits

NMG2 停機時間量測系統
Stop Time Measurement System

專為工業安全設計的便攜式測量系統，依據 EN ISO 13855 標準精確測量機械停機時間，協助工程師計算與驗證安全距離，保障操作人員安全。

符合 ISO 13855
系統內建標準運算公式，自動計算安全光柵或雙手控制裝置所需的最小安全距離。
內建打印機
整合式點矩陣打印機，測試完成後可立即列印包含時間戳記的測量協議，方便現場歸檔。
智慧數據管理
具備 RS232 介面，可連接 PC 並透過 NMG2 WINSOFT 軟體進行詳細的數據分析與歷史記錄管理。

1. NMG2 Stop Time Measuring System (主系統)

NMG2 Main Unit
手持式測量主機，整合顯示、控制與打印功能。內建微處理器，可直接計算安全距離。
功能 停機時間 / 速度測量
顯示 LCD 螢幕 + 鍵盤
輸出 內建打印機 / RS232
電源 電池供電 (便攜式)
ISO 17025校正 核心設備
查看詳細規格

完整的安全認證

每一台 NMG2 主機出廠時皆附帶符合 ISO 9001 與 ISO 17025 標準的校正證書，確保測量數據的公信力。

2. NMG2 Accessories (選配件)

NMG2-AKTOR Drive Unit
自動驅動裝置，透過釋放旗標來模擬光柵 (Light Curtain) 中斷。
用途 模擬光幕中斷
特點 自動釋放，消除誤差
自動化測試
NMG2-MESSRAD Measuring Wheel
測量輪配件，用於檢測移動元件 (如輸送帶) 的線性速度與停止距離。
測量 線性距離 / 速度
原理 增量編碼器
接觸式測量
NMG2 WINSOFT Software
Windows 專用軟體，執行數據記錄、圖表分析並管理歷史測試報告。
平台 Windows OS
介面 RS232 連線
數據歸檔

行業應用實例 (Applications)

沖壓機與剪床
精確測量滑塊停止時間，設定雙手啟動與光柵的安全距離。
工業機器人
驗證機械手臂在緊急停止訊號觸發後的煞車距離與時間。
自動化產線
定期檢測各類電動機械設備的安全性能，符合勞安法規。
安全稽核
作為第三方安全檢查單位的標準校驗工具，提供客觀數據。
