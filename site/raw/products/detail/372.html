PID CONTROLLER

DRT4 Series Temperature Controller

新一代智能 PID 溫控器。搭載 RS-485 Modbus 通訊與自整定 (Auto-Tuning) 演算法，實現精準恆溫控制與遠端數據採集。

● RS-485 Modbus RTU
● 萬用輸入 (TC/RTD/Analog)
● PID 自動演算功能

Smart PID Control

精準恆溫，數據聯網新標準

DRT4 系列搭載先進的 PID 自動演算 (Auto-tuning) 與 Fuzzy 邏輯控制，能快速達到目標溫度並抑制超調 (Overshoot)。全系列標配 RS-485 通訊，讓傳統溫控系統輕鬆升級為工業 4.0 智慧聯網架構。

24-bit ADC

Multi-Input Selectable
 

萬用輸入，一機搞定

工程師無需再為了備料煩惱。DRT4 支援軟體切換多種輸入訊號，包括熱電偶 (K, J, T...)、白金電阻 (PT100) 與類比訊號 (4-20mA, 0-10V)，大幅降低庫存壓力。

  • ✓ 24-bit 高解析度 ADC，採樣精準
  • ✓ 雙組輸出控制 (加熱/冷卻) 支援

RS-485 Modbus 遠端監控

透過兩條通訊線，即可將現場溫度數據即時回傳至 PLC 或 SCADA 系統。支援參數遠端寫入，不僅能實現集中監控，更能透過數據分析優化製程效率。

  • ✓ 支援 Modbus RTU / ASCII 協議
  • ✓ PV (現在值) / SV (設定值) 傳送

行業應用實例 (Applications)

工業烤箱恆溫

DRT4 的自動演算功能可適應烤箱的熱慣性，快速穩定溫度，並透過警報輸出防止過溫意外。

搭配: SSR / SCR
塑膠押出溫控

多段溫控對應押出機的料管加熱區。加熱/冷卻雙輸出控制，確保塑料在最佳熔融溫度下成型。

搭配: 4-20mA 輸出
食品包裝封口

精準控制封口刀溫度，避免溫度過低造成密封不全，或過高導致包材焦黑。

搭配: SSR 驅動
