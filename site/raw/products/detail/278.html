Harmonic Drive® Component Set

極致薄型・貫穿中空軸
CSD Series Component Set

CSD 系列元件型減速機專為「極致短小」的空間需求而生。透過外張式 (Silk Hat) 彈性齒杯設計，實現了驚人的軸向薄型化與大口徑中空孔，是小型機器人與精密末端效應器的核心首選。

大口徑中空設計

解決線纜纏繞，簡化機構設計。

外張式結構，釋放中央空間

CSD 系列採用特殊的 外張式 (Silk Hat Type) 彈性齒杯。這種結構移除了傳統杯型的封閉底部，在減速機中央形成一個開放的 大口徑中空孔。

這使得複雜的信號線、電源線或雷射光束可以直接穿過軸心，無需使用滑環，大幅提升了機械手臂手腕與旋轉平台的可靠性。

極致短軸長

業界最薄型設計，節省寶貴空間。

空間利用的魔術師

CSD 元件型僅由 波產生器、柔輪 與 剛輪 三個核心部件組成。相較於 SHG/SHF 系列，CSD 進一步優化了軸向長度。

這種緊湊設計讓工程師能夠在極其有限的空間內（如人形機器人關節、半導體末端效應器）植入高扭矩動力源，同時保持 零背隙 (Zero Backlash) 的高精度特性。

晶圓搬運機器人

機器人末端效應器
